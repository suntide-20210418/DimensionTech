## 统一风格

以下提示词均默认：`Minecraft Java 16x16 pixel art texture, crisp hard edges, no text, no logo, centered orthographic cube, four visible faces, tileable, transparent-free opaque texture, strong readable silhouette, restrained industrial sci-fi palette`。每个条目可直接复制到绘图模型；将方括号内容视为该方块的专属描述。
