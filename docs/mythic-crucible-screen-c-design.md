# 神话熔炉 GUI 重构 · 方案 C 像素级规范

> 本体极简 + 右侧页签信息面板。本文档是画图与实现双方的唯一几何依据。
> 所有坐标为 GUI 局部像素（相对面板左上角）。`MythicCrucibleScreen` 不做 pose
> translate，渲染时一律 `leftPos + x` / `topPos + y` 绝对坐标，scissor 直接用绝对坐标。

## 4. 三页内容排版

行高均 11px；分节头前留 5px 额外间距；`INK`=黑，`AMBER #8A5A14`，`FLUIX #2A6180`，
`SUCCESS #2E6B3E`，`ERROR #A6442F`。**一律 9px，禁止缩比**；单行超 92px 截断加「…」，
全文进 tooltip。

### 4.1 状态页（默认页）

| 行 | 内容 | 颜色 |
|---|---|---|
| 分节头 | 当前状态 | INK |
| 1 | `运行中 · 阶段 3/7` | INK |
| 2 | `阶段进度 83 / 400 t` | INK，数值 FLUIX |
| 分节头 | 奖励窗口 | INK |
| 3 | `200 ~ 300 t · 未进入` | AMBER（已进入改 SUCCESS） |
| 分节头 | 本步需求 | INK |
| 4.. | `· 回响碎片`（每个候选一行，最多 3 行） | INK |
| n | `还有 3 种…`（超出时） | INK |
| n+1 | `流体 ≥ 500 mB` | FLUIX |
| 分节头 | 配方修正 | INK |
| n+2 | `产出 +12%` | 正 SUCCESS / 负 ERROR |
| n+3 | `流体 −8%` | 同上 |
| n+4 | `耗时 −40 t · 碎片 +1` | 同上 |
| 分节头 | 上次结算 | INK |
| n+5 | `正确 · 产出 +12%` / `失误 · 罚时 +200t` | SUCCESS / ERROR |

整页约 17 行 × 11px ≈ 187px > 视口 114px → 滚动。

### 4.2 序列页

- 每行 12px：`序号 + 阶段名`，如「3 递归」。
- 当前行：底色 `SELECT #77909F` 高亮条，文字 INK；已完成行 INK；未到行 INK + 前置「·」。
- 32 行 × 12px = 384px，滚动承载。不再用 `→` 拼接的一行流。

### 4.3 记录页

- 每行 11px，一次结算一行：`#12 递归 · 正确 · 产出+12%`（成功 SUCCESS / 惩罚 ERROR）。
- 最新在上，滚动查看历史；数据源为服务端已有结算事件，存量显示「暂无记录」。

## 5. 纹理绘制清单（画图依据）

画布 **320×256 RGBA**，`assets/dimension_tech/textures/guis/mythic_crucible.png`。

### 要画

1. **主面板底** `(0,0,293,165)`：面 `FACE #C6C6C6`；外缘 1px `HAIRLINE #000000`，
   上/左 1px `HILIGHT #FFFFFF`，下/右 1px `SHADE #555555`（与采掘器面板同一套凸起风格）。
2. **罐体框** ×2 `(8,17,16,50)`、`(152,17,16,50)`：凹陷井——内填 `WELL #808080`
   （内区 `(9,18,14,48)`），边框上/左 `SLOT_SHADE #2F2F2F`、下/右 `SLOT_HILIGHT #565656`。
3. **进度轨凹陷** `(73,22,73,6)`：内填 `WELL`，1px 暗边。
4. **右面板凸起** `(177,17,112,143)`：`FACE` + 与主面板同风格边框（视作内嵌面板）。
5. **视口凹陷** `(181,41,102,114)`：内填 `WELL #808080`，1px 暗边。
   （文字直接写在 WELL 上 —— 视口内文字 token 用 `TEXT/MUTED` 系浅色，
   分节头可用 `HILIGHT`；这是本规范唯一允许浅字的区域。）
6. **物品栏/快捷栏槽位网格** `(7,83,162,54)`、`(7,141,162,18)`：
   **从旧 200×200 纹理同区域逐像素复制**（该区域几何未变）。
7. **流体刻度条** 保留在 `(195,0,5,41)`，UV 常量不变。

### 不画（由代码从 spritesheet / 程序化绘制）

- 18×18 槽位底图（spritesheet `(0,80)`/`(18,80)`）
- 32×16 页签（spritesheet `(0,48)`/`(32,48)`）
- 进度条填充（spritesheet `(80,0)-(95,3)`，裁剪平铺）
- 状态 chip / 奖励窗 chip（程序化）
- 滚动条（程序化）
- 一切文字

### 废弃

- 旧 `(52,18,93,47)` 状态框底纹
- 旧 `(176,0,12,11)` 竖进度条覆盖

## 6. 色板速查（`GuiPalette`）

| token | hex | 用途 |
|---|---|---|
| FACE | `#C6C6C6` | 面板面 |
| WELL | `#808080` | 凹陷（罐、视口、进度轨） |
| HAIRLINE / SHADE / HILIGHT | `#000000` / `#555555` / `#FFFFFF` | 边框 |
| SLOT_SHADE / SLOT_HILIGHT | `#2F2F2F` / `#565656` | 凹陷边 |
| SELECT | `#77909F` | 序列页当前行底色 |
| TEXT / MUTED | `#E6E6E6` / `#A9A9A9` | **仅限 WELL 深底上**（视口内） |
| INK / DIM | `#000000` | 浅底 FACE 上的所有文字 |
| AMBER / FLUIX / SUCCESS / ERROR | `#8A5A14` / `#2A6180` / `#2E6B3E` / `#A6442F` | 浅底强调色 |

> 注意与既有约定的衔接：机体区（FACE 浅底）文字全黑 + 强调色；
> 右面板视口是 WELL 深底，用 `TEXT/MUTED`，数值强调色改用 `WELL_*` 系
> （`WELL_AMBER #C8943C` / `WELL_FLUIX #70C9E4` / `WELL_SUCCESS #6EA27F` / `WELL_ERROR #E08A7A`）。
> 若希望视口也保持黑字，把视口内填从 `WELL` 改为 `FACE` 即可，二选一，画图前定。

## 8. 交互规范

- 页签点击区 = 页签矩形；切页时滚动归零。
- 滚轮：指针在右面板矩形 `(177,17,112,143)` 内即滚动当前页（**无更细的位置门**，
  采掘器滚轮事件的教训）；`scroll -= signum(delta) × 11`。
- 滚动条：抓取式拖拽；判定先于页面点击分发。
- 键盘：PgUp/PgDn/Home/End 翻页滚动（GLFW 266-269）；ESC 关闭。
- tooltip：罐体/两槽维持现有逻辑；页面行级 tooltip 与点击复用同一套命中测试
  （如「本步需求」截断行给出完整候选列表）。
